# FuwaFuwa イラスト制作ブリーフ（全バッチ共通）

FuwaFuwa は無料・商用利用OKのイラスト素材サイト（8言語）。全イラストを同じ画風で揃える。
リポジトリ: /home/claude/rakuearn-blog （作業はここで。自分のバッチの2ファイル以外は絶対に編集しない）

## 作るもの（バッチID を bNN とする）
1. `art_items/bNN.py` — 描画定義
   ```python
   from art import z, s, dot, cheeks, face, OUT, CH
   ITEMS = {}
   ITEMS['cat-sitting'] = (z('ellipse', '#f5b971', cx=100, cy=140, rx=40, ry=38) + ...)
   ```
   キーはURLになる英語スラッグ（小文字・ハイフン区切り、ブリーフで指定されたもの）。値はSVG本体の文字列。
2. `data/items/bNN.json` — メタデータ（同じスラッグ・同じ順番）。形式は `data/illustrations.json` と完全に同じ：
   `[{"slug": "...", "cat": "...", "date": "2026-10-17", "t": {"en": [title, description, [tag, tag, tag]], "ja": [...], "es": [...], "pt": [...], "fr": [...], "de": [...], "zh": [...], "ko": [...]}}]`
   - 8言語すべて必須（en, ja, es, pt(ブラジル), fr, de, zh(簡体字), ko）。各言語のネイティブが素材を探すときに使う自然な言葉で。
   - title は短い名詞句（例「おすわりする子犬」）、description は1文、tags は3〜4個（検索されやすい語）。
   - zh は簡体字。pt はブラジル式（celular など）。JSON は ensure_ascii=False で整形して保存してよい。
   - cat は指定どおり（people, work, animals, food, nature, home, tech, school, travel, events, sports, health, hobby のいずれか）。

## 画風ルール（最重要）
`art.py` を最初に読み、既存10点（I['01_hello']〜I['10_cake']）の描き方を真似ること。
- キャンバスは 200×200。主題は x,y ともおよそ 25〜180 の範囲に収め、はみ出さない。主題は中央で大きめに（既存10点と同程度の大きさ）。
- 線は全体共通でこげ茶 `#3b2f2a`、太さ3（`svg()` のラッパーが付ける。個別に stroke_width で細くするのは小物だけ）。
- 「ズレ塗り」：色付きの面は必ず `z(tag, fill, ...)` で描く（色が右下に4pxずれ、線は元位置）。これがこの画風の核。
- `s()` は線だけ／ずらさない小さな塗り（模様・窓・ほっぺ等）に使う。
- 顔のある人物は `face(cx, cy, skin, hair, mouth)` を使う（mouth='smile' / 'open' / 'o'）。目は点、ほっぺはピンク。
- 動物・擬人化した物も、点の目＋ピンクのほっぺ＋小さな口を基本にする（すべての物に顔を付ける必要はない。既存の飛行機・家・ギフトには顔がない）。
- 配色は既存の柔らかいパレットから選ぶ：#f5b971 #7cc4b0 #e8735a #8fc7e8 #9ccf7a #f5d58a #f6e0c4 #f6a6b8 #f07a8a #8fb3e0 #d9a66b #9a6a3f #b9a99c #5b6b7a #ffe27a #ffffff #f4f4f0 #c9d3db #8b6b4f #7cc4a0 #ffc94d #e04b5a #a98bd0（紫・ぶどうやなす等） #7a5ea8（濃い紫）
  肌色は標準の肌色 #ffd9b8 で統一する（茶色系の肌色は使わない）。サイトの「肌の色切り替え」はこの色を置き換えて動くので、人の肌（顔・手・足）には必ず #ffd9b8 を使い、肌以外のもの（食べもの・家具など）には #ffd9b8 を絶対に使わないこと。髪色 #5a4033 #2b2220 #c9a36b #e8e1d8（白髪）など。
- 文字・数字・ロゴ・国旗・実在ブランド・既存キャラクター・宗教的シンボルは描かない（言語に依存しない素材にするため）。
- グラデーション、影、フィルター、テキスト要素は使わない。フラットな塗り＋線だけ。
- パスの塗り：線だけのパスには fill を付けない（s('path', d=...) は fill='none' がデフォルト）。
- 人物の体は既存のように「頭＋丸い胴体」のゆるい2頭身〜2.5頭身。手は丸や太線でよい。
- 頭と体（服）の間にすき間を空けない。胴体の上端は頭の円の中（あご下）まで入れて、頭が体に乗っているように描く（頭が浮いて見えるのはNG）。
